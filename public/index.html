    Is my key safe?
    • Just this visit: the key lives only in this tab's memory. It is never written to the database or to your browser's storage.
    • Save (encrypted): the server stores it encrypted and shows only the last 4 characters, never the full key again.
    • Use a key made just for this app, ideally with a spending limit, so you can revoke it any time in your provider's console.
    • A model is only used after it passes a connection test.
